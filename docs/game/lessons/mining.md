## L26 · ★ 采矿要一次批量 `predict` 多框（6~8 个）：同区风险能从 3% 跳到 66%

- **症状**：2026-10-18 本鱼第一次量到某个框 `baseAttackChance = 24%`，当场说「太危险，换位置」；后来一次量 8 个框才发现同星区里有 **3% / 9%** 的框，最终在 9% 的框挖到 **16.5~20.6 万/h Trinium**。
- **当时的错误判断**：一个框一个框试、看到高风险就换方向；把「这个框危险」当成「这片都危险」。
- **错因**：伏击概率是按**框覆盖的星区**算的（`SimulationUtility.calculateAttackProbability(ownerIndex, shipName, area, …)` 的 `area` 参数），同一星区里框挪几格，覆盖到的巡逻/海盗星区就变了 → 风险可以剧烈跳变，而**产出几乎一样**。单框采样 = 拿一个样本给整片下结论 ✗。
- **正确判据**：一次 `predict {ship, action:"Mine", boxes:[{x,y,sizeX,sizeY,duration}, …]}` 量 **6~8 个框**（N≤24）；先按 `box.containsShip == true` 与 `risk.baseAttackChance ≤ 0.10` 过滤，再比 `value`（产出/材料档），挑**风险低且产出高**的那个下单 ✓。风险跨度大是常态，别用单框的 24% 否定整片。
- **证据出处**：批量 `boxes` N≤24 `data/scripts/net/link_in.lua:7185-7186`、每框独立 `:7207` ✓；风险按 `area` 计算 `simulationutility.lua:617`（签名）+ `minecommand.lua:853`（调用）✓；2026-10-18 实测 8 框（3%~66%），9% 框 16.5~20.6 万/h Trinium（会话记录）✓。

## L29 · ★ 采集类量框先把船放到框的**角格**上：同一张 15×15 框，覆盖从 1 倍变 4 倍（2026-10-20）

- **症状**：`Salvager-00002` 在 (-203,-64)，同一时刻量同一片：框心打在船上 (-203,-64) → **13% / 6~9 件 / 4.6~5.8 万**；框心挪到 (-196,-57)（船正好落在框角）→ **73% / 11~15 件 / 12.0~14.9 万**；同样的贴角框再带上 `escorts:[Raven]` → **2% / 22~30 件 / 12.1~15.2 万**。产出翻倍、风险还能压到 2% —— 而早先那次是 13% 的低产出框，主人当场问「收益怎么不高」。
- **当时的错误判断**：把「框心可在仍含船的约束内平移」理解成「框心默认放船上就行」，量框一律沿用 offset (0,0)；也就从没想过船的**站位**会决定它够得到哪些星区。
- **错因**：采集类区域是**以框心为准**的固定形状（Mine/Salvage 15×15、半宽 `floor((size-1)/2)=7`）—— 框心打船上，船只够到 **±7** 半径；把船贴到角格，同一张框里船能触及 **±14**，覆盖变成 **4 倍** ✓。所以「挪框」其实有两条路：挪框心（受「必须含船」的 ±7 约束）和**站到框的角上**（同样合法、但把船的作业半径顶满整个框）—— 以前只会走第一条，白丢一半以上覆盖。
- **正确判据**：① **采集类量框前先把船放到框的一个角格上**（框心 = 船 ∓7），再 `predict`；不要习惯性把框心打在船上。② 想够到某个方向的高产出区 → **把船贴到那个方向的角**，而不是把框心挪过去（挪过 ∓7 船就出框）。③ 贴角拿到的高产出框被风险挡住时，先带**在 reach 内**的护航重测（73% → 2% 真机 ✓）再判，别直接退回低产出框。④ 贴角是**合法的**：原版含船判定是**闭区间**、比的是 `getShipPosition` 的**原始坐标**（`simulation.lua:547-548` ✓），船停在整数星区时 ±7 的四个角都算含 ✓（2026-10-20 真机四框全 `true` ✓）；但船**在跳跃途中坐标是小数**，此时按整数格拼的贴角框原版会判不含 → 贴角前用 `predict` 回的 `shipPosition{x,y,cellX,cellY}` 核一下，船在动就重量（[`boxes.md`](boxes.md) L1 同源 ✓）。
- **证据出处**：2026-10-20 真机会话三组同刻对照（13% / 73% / 带 Raven 2%）✓；区域以框心为准 + 半宽 `floor((size-1)/2)` = 7 → [`../mechanics/areas-and-boxes.md`](../mechanics/areas-and-boxes.md) L10、L13（`simulation.lua:546`、`link_in.lua:385-389` ✓）；含船判定 = 闭区间 + 原始坐标 `simulation.lua:547-548` / `:824-825`（`x >= lower.x and … <= upper.x`，**不取整** ✓），本 mod 同口径 `link_in.lua:1010` / `:2331` / `:6902` ✓，真机四贴角框全 `true` ✓；护航不在 reach 内时 `escorts` 静默无效（同框带 / 不带数字不变、不报错，`4.12 > 4.10`）见 [`escorts.md`](escorts.md) L28 ✓；Refine 的 31×31 由原版**按船重算**（`refinecommand.lua:318-320`、`simulation.lua:790-801` ✓）→ 「贴角」对它无从谈起 ⚠未验证。
