# 会话接管（DECIDE 的所有权）

> 主人 2026-10-14 定的约束：
> **「不能让每个会话都处理，仅能让一个会话处理。我认为你应该在界面上加个开关，
> 从这个会话打开，就是这个会话接管，其它会话放弃接管。」**

## 铁律

**同一时刻，`decide` 只能由一个会话处理** ✓✓ —— 否则几个会话同时决策，
会给同一艘船下互相冲突的命令 ✗（而且谁也不知道对方干了什么 ✗）。

## 三种状态

| 状态 | 谁处理 `decide` |
|---|---|
| **无人接管** | 插件自己调模型 ✓（**兜底**：舰队不停摆 ✓） |
| **会话 A 接管** | **只有 A** ✓；B 来问时**明确告知"A 在接管"** ✓✓ |
| **租约过期** | 回到无人接管 ✓（A 崩了/关了也不至于让舰队瘫痪 ✓✓） |

## 数据结构（插件内单例，运行期状态 ✓）

```
owner      : 会话 id | nil          —— 谁在接管 ✓
leaseUntil : 时间戳                  —— 租约到期时刻 ✓
pending    : 船名 -> { at, request } —— 等 owner 决策的船 ✓
```

## 工具

```
fleet_takeover { on: true }
    空闲            → ★ owner = 当前会话，租约 = now + 60s ✓✓
    别人占着         → **明确拒绝** ✓，并回报 owner 是谁 ✓（不许静默失败 ✗）
    是我自己         → 续期 ✓

fleet_takeover { on: false }
    只有 owner 能释放 ✓；非 owner 调用 → 拒绝 ✓

fleet_status
    任何会话都能看 ✓ ——「现在谁在接管 / 还有多少船在等」✓

fleet_pending
    ★ 只有 owner 能取 ✓；非 owner → 拒绝并告知 owner ✓✓
```

## 租约（**必须有** ✗✓）

`owner` **每次调用工具都续期 60 秒** ✓；超过 60 秒没有动静 → **自动释放** ✓✓。

> 若没有租约 ✗：会话一崩 / 一关，`owner` 就永远挂着 → **舰队永远没人决策** ✗✓
> 这正是本仓库那条硬规矩的又一例：「凡是'只做一次'的守卫都是定时炸弹」✓
> 所以这里必须写成**会自己过期**的 ✓✓。

## 界面上的开关

主人要"界面上加个开关" ✓。DSH 侧两种做法（择一即可 ✓）：

1. **插件命令** ✓ —— 已装插件 `dsh-global-memory` 的 `inject` 里有 `'commands'` ✓，
   说明插件能注册命令 ✓ → 主人在 DSH 里敲一条命令即接管/交出 ✓✓（最省事 ✓）
2. **会话内的工具调用** ✓ —— 主人直接说"你接管舰队" ✓，本 agent 调 `fleet_takeover` ✓✓

> 注：**游戏侧的 Copilot 面板**是另一个界面 ✗ —— 它管的是"哪些船交给 AI 运营"（名单 ✓）
> 与"每艘船的目标" ✓；**会话接管属于 DSH 侧** ✓，两者不要混 ✓✓。
